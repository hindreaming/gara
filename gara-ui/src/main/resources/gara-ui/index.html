Object Browser

Gara is just a fun project, made for fun, learning and experimenting; it is not a production-grade storage service. It keeps files in GitHub repositories, so use it responsibly: excessive bulk uploads or large-scale hosting can break GitHub's Terms of Service and get the account rate-limited or suspended. Keep it to modest, personal, non-commercial use. There are no guarantees, so keep your own backups.

Buckets are stored in Postgres; each one writes to its own GitHub repositories.
