GARA Sandbox

Try Gara

Drop a file and Gara stores it in a public GitHub repository, the same way it stores objects sent through its S3 API. You get a public link to the file and to the repository.

Uploads here are public and permanent. Anyone can see them, and they stay in the repository's git history even after deletion. Do not upload anything private, sensitive or illegal.

Gara is just a fun project, made for fun, learning and experimenting; it is not a production-grade storage service. Please use it responsibly: it keeps files in GitHub repositories, and bulk uploading breaks GitHub's Terms of Service. No guarantees. The daily limits are shared by every visitor and reset at midnight UTC.
